## Project Description

The Academic Course & Schedule Planner is a web-based application designed to help university students organize their academic semesters.

Students can explore available courses, check prerequisites, build conflict-free timetables, calculate semester and cumulative GPA estimates, and monitor their academic progress through visual dashboards.

Administrators can manage courses, section offerings, capacities, prerequisites, and grading rules.
